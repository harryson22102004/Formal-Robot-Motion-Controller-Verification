# Formal Robot Motion Controller Verification
Applying formal methods to guarantee the safety and correctness of robotic navigation controllers.

### 🔬 Research Highlights
- **Invariant Checking**: Uses logic-based verification to ensure robot trajectories stay within safe boundaries.
- **Controller Modeling**: Simulates motion primitives and verifies them against reachability constraints.
- **Robotics Focus**: Combines Control Theory with Formal Verification for high-reliability systems.

**Tech Stack:** Python, `Z3` (SMT Solver).
